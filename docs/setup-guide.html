jobhunt-agent · setup guide

Set up your daily job-hunt routine

Claude searches job boards every morning, scores new ads against your CV and, on weekdays, drafts a tailored CV and cover letter for the best ones. You review and send them yourself; nothing is ever submitted for you.

  1. You

    Install the tools

    • Claude Desktop, signed in, with the Code tab available.
    • Python 3 (tick "Add to PATH") and Git.
    • Microsoft Word, if you want PDFs. Without it you still get the .docx files.
    pip install python-docx openpyxl pypdf pyyaml requests
  2. You

    Create your workspace

    Pick a permanent place, such as Documents. The engine is cloned inside your own folder; the check script copies the templates and creates the folders without touching anything that already exists.

    mkdir JobHunt
cd JobHunt
git clone https://github.com/Jaival/jobhunt-agent engine
python engine/tools/setup_check.py --init

    The last line ends with a list like this. You don't have to fill it in by hand; the first run asks you for it.

    ok    config.yaml: file
TODO  config.yaml: applicant  -> set applicant (onboarding asks for it)
TODO  cv: master CV  -> put your master CV (.docx) at cv/...
TODO  profile: CLAUDE.md  -> fill in your profile (onboarding asks for it)
ok    workspace: tracker/Job_Application_Tracker.xlsx

NOT READY: 8 item(s) to do
  3. You

    Add the scheduled routine

    In Claude Desktop open the Code tab, then Routines → New routine → Local, and fill in:

    Name
    job-hunt-daily
    Description
    Find, score and tailor jobs; update tracker; write daily brief
    Folder
    your JobHunt folder (trust it when asked)
    Schedule
    daily, e.g. 07:30. Weekends run a short search-only mode.
    Model
    the strongest one you have
    Instructions
    copy the text below
    Run my job-application routine in this folder. Read engine/ROUTINE.md and follow it exactly.
On the first run it checks the setup and asks me for what it needs.
Finish by replying with a 3-line summary and the path of today's brief.
  4. Claude asks

    Click "Run now" and answer the setup questions

    The routine runs setup_check.py first. While something is still TODO it doesn't search; it interviews you in short rounds and writes your answers into config.yaml, CLAUDE.md, projects.md and sources.md.

    1About you2Studies3Roles you want4Languages5CV and letter 6Strengths and gaps7Projects8Rules and daily plan9Search terms10Connectors
    Example conversation
    Your workspace isn't set up yet, so I'll ask a few questions before the first search. Round 1, about you: what's your full name as it should appear on your CV, and which city do you live in?
    Alex Example, Leipzig.
    Thanks. Round 3: which kinds of roles should I look for?
    Working studentInternshipResearch assistant (HiWi)ThesisJunior
    Round 6: your CV clearly supports Python, Docker and GitHub Actions. Which of these could you explain in an interview? I'll only ever claim the ones you confirm.

    Weren't watching when it ran? The routine writes a "Setup needed" brief with the next questions. Reply in that session, or open Claude Code in the folder and say continue the job-hunt setup. Progress is saved after every round.

  5. You

    Allow permissions and keep the computer awake

    • During the first run, choose Always allow for Python, curl and file writes so later runs don't stall.
    • Settings → Desktop app → General: turn on Keep computer awake. Routines only run while the app is open; a missed run catches up once.
    • Optional: connect Gmail and Indeed in Claude, and set up email job alerts on StepStone, XING and LinkedIn. Those sites often block automated searches, and alert emails get through.
  6. Claude draftsYou send

    Each morning, open the brief

    Open daily/<today>.md: the top jobs to apply to, drafts waiting in applications/, follow-ups due and a short plan for the day. Check each draft, send it yourself, then tell Claude "I sent the application to …" and it is added to the tracker.

What lives where

Your private filesThe public engine (updated with git pull)
JobHunt/
├─ CLAUDE.md          who you are, your decisions
├─ config.yaml        name, CV paths, letter city, search area
├─ projects.md cv/    your projects and master CV
├─ sources.md         search terms and job boards
├─ applications/      one folder per tailored draft
├─ daily/ tracker/    briefs and the sent-applications tracker
└─ engine/            ROUTINE.md, RULES.md, ONBOARDING.md, tools/

What it will never do

Send anything

No applications, emails or posts. You get drafts; you decide.

Invent facts

Every claim comes from your CV or what you confirmed during setup.

Obey job ads

Ad text is treated as data. Hidden "AI, do this" instructions are reported, never followed.

If something goes wrong

It keeps asking setup questions
Run python engine/tools/setup_check.py in the folder. Every TODO line says what is missing.
"CV map" warning
The builder finds the parts it may change (headline, item order, letter text) through cv/layout.yaml, a map of your own CV. If you edited your master CV since it was mapped, say "remap my CV". Until the map works you get the letter text and CV choices, but no finished documents.
The tracker didn't update
Close it in Excel before the run. Rows that couldn't be saved wait in tracker/pending_rows.csv.
Updating the engine
Run git pull inside engine/. Your own files are never touched.
